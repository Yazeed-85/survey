# استبيان الوردة 🌹

صفحة واحدة (`index.html`): دخول ← طرفية Lamar ← وردة ثلاثية الأبعاد تتفتح ← استبيان ← شكر + ختم "كفو" ← عودة للبداية.

## الملفات
- `index.html` `style.css` `app.js`: الموقع والمشاهد
- `rose3d.js` `roseview.js` `rose.js`: الوردة (ثلاثية الأبعاد، وSVG احتياطي إن لم يتوفر WebGL)
- `audio.js`: الأصوات (مولّدة بالكود)
- `config.js`: Firebase والأسئلة الافتراضية وكلمة مرور اللوحة
- `dashboard.html`: لوحة التحكم (كلمة المرور الحالية: `rose2026`)
- `vendor/`: GSAP و three.js

## النشر
GitHub ← Settings ← Pages ← Deploy from branch ← `main` / root.

## ملاحظات
- أول نقرة على "دخول" تشغّل الصوت والعرض معاً (شرط المتصفحات). زر 🔊 يكتم.
- الأسئلة تُعدَّل من اللوحة (تبويب الأسئلة) بدون إعادة رفع، أو من `config.js`.
- كلمة مرور اللوحة تغلق الواجهة فقط؛ قواعد Firebase مفتوحة (انظر `FIREBASE_RULES.md`).
